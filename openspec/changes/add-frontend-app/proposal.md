# Change: NextJS Dashboard Application

## Why
B2B SaaS needs a protected dashboard application with authentication, team management UI, billing management, and settings. The app integrates with the Django backend via JWT authentication.

## What Changes
- Create NextJS 15 app in /app
- Implement JWT authentication flow
- Create dashboard layout with sidebar navigation
- Add team management pages
- Add billing and subscription pages
- Add user settings pages

## Impact
- New capability: frontend-app
- Primary user interface for authenticated users
