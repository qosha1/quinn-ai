# Change: NextJS Landing Page

## Why
B2B SaaS needs a marketing landing page with modern design, SEO optimization, and conversion-focused sections. Using v0.dev patterns with shadcn/ui provides a polished, maintainable foundation.

## What Changes
- Create NextJS 15 landing page in /landing
- Configure Tailwind CSS with shadcn/ui
- Add common landing page sections (hero, features, pricing, FAQ)
- Implement dark mode support
- Add SEO metadata and structured data

## Impact
- New capability: landing-page
- Marketing and conversion entry point
